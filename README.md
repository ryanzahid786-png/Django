# 🐍 Django To-Do Web Application

A beginner-friendly Django web application featuring a database-backed To-Do List, Home page, About page, and Django Admin panel.

This project is designed to demonstrate the fundamentals of building, running, and managing a Django web application using Python.

---

## 📌 Project Overview

This project demonstrates a complete beginner-level Django application with:

- 🏠 Home page
- 📝 Database-backed To-Do List
- ℹ️ About page
- 🔐 Django Admin panel
- 💾 SQLite database
- 🌐 Django development server
- 📦 Python virtual environment
- 📋 Step-by-step setup instructions

---

## ✨ Features

- Create and manage To-Do tasks
- Mark tasks as completed
- Delete tasks
- Store tasks using a database
- Access and manage tasks through Django Admin
- Simple HTML templates
- Easy local development setup
